# Triage Labels

The skills use five canonical triage roles. This table maps each role to its label in this repo's GitHub issue tracker.

| Canonical role | GitHub label | Current status |
|---|---|---|
| `needs-triage` | `needs-triage` | Not present |
| `needs-info` | `needs-info` | Not present |
| `ready-for-agent` | `ready-for-agent` | Present |
| `ready-for-human` | `ready-for-human` | Not present |
| `wontfix` | `wontfix` | Present |

When a skill mentions a triage role, use its corresponding label from this table. The missing labels are documented as intended names; this setup does not create them on GitHub.
